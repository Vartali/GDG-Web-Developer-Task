# GDG ProjectHub

A responsive student project showcase and feedback platform built for the GDG on Campus AITR Web Developer Task.

## About the Project

GDG ProjectHub allows students to showcase their projects, discover projects created by other students, and provide feedback.

The project was designed with a focus on simple navigation, responsive design, and interactive features.

## Features

- Responsive desktop and mobile design
- Project search
- Category filtering
- Submit new projects
- Project upvoting
- One upvote per project per browser
- Project feedback/comments
- Data persistence using localStorage
- Responsive submit-project modal
- Interactive navigation
- Mobile-friendly layout

## Categories

Projects can be submitted under:

- Web
- AI
- Mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How It Works

Projects and user interactions are stored in the browser using `localStorage`.

This allows submitted projects, upvotes, and feedback to remain available after refreshing the page.
